# Decision: lean host-union pulls non-lean member content (accepted, #603)

Lean membership is granted per host and judged by union value: a host enters
lean only if its entire consolidated body — including formerly non-lean
members' content — justifies primary visibility. Member-level exclusion is
unsupported because lean keys must match skill dirs on disk
(tests/skill_profiles.bats). Cost direction: per-session description tax
FELL 78→67; only per-invocation payload grows (host bodies are modest).
Confirmed by Mode R 2026-09-27; Wave 2 host-selection criterion.
